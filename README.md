# Reservasi Kelas

Project web **Reservasi Kelas** berbasis Laravel.

Aplikasi ini digunakan untuk membantu proses reservasi / peminjaman ruang kelas oleh mahasiswa dan pengelolaan data oleh admin.

## Teknologi
- Laravel
- Blade Template
- Vite
- Bootstrap
- MySQL

## Cara Menjalankan
1. Clone repository
2. Install dependency
3. Jalankan server

## Catatan
Project ini dibuat untuk keperluan pembelajaran dan kerja tim.
